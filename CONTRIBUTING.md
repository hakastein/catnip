# Участие

Задачи и предложения — [GitHub Issues](https://github.com/hakastein/catnip/issues), изменения — пулл-реквестом в
`main` из своей ветки.

## Границы

catnip читает и правит файлы и сцепляется в bash. Поиск, навигация по коду, правка многих файлов по шаблону,
MCP-сервер и хуки конкретных агентских сред — вне рамок. catnip не называет конкретных агентских сред и
инструментов навигации; совместимость с ними — только через формат позиций `путь:строка[:колонка]`.

## Проверка

```bash
make go   # gofmt, go vet, go test; сборка без CGO
```

CI гоняет то же на Linux, macOS и Windows. Правила кода и тестов — [`AGENTS.md`](AGENTS.md). Изменение поведения
отражается в справке команды (`catnip <команда> --help`), [README](README.md), [скилле](skills/catnip/SKILL.md) и
[CHANGELOG](CHANGELOG.md); изменение конфига — ещё и в [скилле настройки](skills/catnip-setup/SKILL.md).

## Релизы

Тег `vX.Y.Z` ставит владелец; у каждого тега есть раздел в `CHANGELOG.md`. Тег запускает
`.github/workflows/release.yml`: `make dist` собирает бинарники и `sha256sums.txt`, раздел CHANGELOG становится
описанием релиза.
