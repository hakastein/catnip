# catnip

CLI для агентов: просмотр и правка файлов, сцепляемые в bash. Задачи — GitHub Issues этого репозитория.

## Правила

- catnip — самостоятельный инструмент со своим контрактом. Ни код, ни тесты, ни документы не называют конкретных
  харнессов и инструментов навигации; совместимость с ними — только через формат позиций `путь:строка[:колонка]`.
- Работа идёт веткой от `main` и пулл-реквестом в `main`; в `main` напрямую не пушат.
- Сборка без CGO: `CGO_ENABLED=0` в `Makefile` и CI.
- Go простой и скучный: интерфейс объявляет потребитель, нового понятия под гипотетический случай нет.
- Документы и комментарии описывают текущее состояние.
- Проверка — `make go`: gofmt, `go vet`, `go test`. CI — `.github/workflows/ci.yml`.
- Репозиторий публичный: в коде, документах, задачах и PR нет личных данных, путей и проектов владельца, данных
  его исследований и всего, что не относится к catnip.
- У каждого тега `vX.Y.Z` есть раздел в `CHANGELOG.md`; тег запускает `.github/workflows/release.yml`.

## Тесты

- Каждый модуль (`internal/*`) тестируется через свой экспортированный интерфейс. У CLI — только короткие проверки
  кодов выхода.
- Тест во внешнем пакете `_test`, на testify и таблицах: случай — строка «вход → ожидаемый результат или ошибка»,
  в теле теста нет логики. `require` — для предусловий, `assert` — для проверок.
- Файлы тест создаёт в `t.TempDir()`; конфиг пользователя подменяется через `XDG_CONFIG_HOME`.
