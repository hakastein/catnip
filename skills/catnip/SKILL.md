# catnip

`catnip` читает и правит файлы одной bash-командой и сцепляется через `&&`. Используй его вместо `sed -n`, `cat -n`,
`sed -i`, heredoc в файл и python-скриптов с `str.replace`.

## Просмотр

```bash
catnip show src/a.php              # весь файл с номерами строк
catnip show src/a.php:40-80        # диапазон
catnip show src/a.php:57           # позиция и 5 строк вокруг; -C N меняет окрестность
catnip show src/a.php:57:12        # позиция с колонкой, как её печатают инструменты на LSP
catnip show --hash src/a.php:40-80 # хеш строки: 57#a3f0 — адрес для правки по строке
catnip show --blame src/a.php:57   # коммит, автор и дата каждой строки
```

Строки и колонки с 1. Диапазон за концом файла — ошибка с реальным числом строк.

## Правка

Пакет из stdin: всё или ничего, по одному или нескольким файлам.

```bash
catnip edit <<'EOF' && make test
@@@ replace src/a.php
    $total = $price * $qty;
@@@ with
    $total = $price * $qty * (1 - $discount);
@@@ end

@@@ replace*2 src/b.php
old_name(
@@@ with
new_name(
@@@ end

@@@ block src/a.php
function legacy() {
@@@ through
}
@@@ with
@@@ end

@@@ after src/a.php
use App\Price;
@@@ insert
use App\Discount;
@@@ end

@@@ replace src/c.php:57#a3f0-59#0b1c
@@@ with
return null;
@@@ end
EOF
```

- `replace` — заменить текст; `block` — от начального якоря до первого конечного после него, оба включительно;
  `before`/`after` — вставить у якоря. Пустой текст после `@@@ with` удаляет.
- Текст между маркерами берётся как есть, с переводами строк: экранировать кавычки, `\` и `$` не нужно. Строка
  управляющая, только если начинается с `@@@ ` в первой колонке.
- Искомый текст должен найтись ровно один раз, `verb*N` — ровно N раз (правятся все). Иначе не пишется ни один
  файл, а ошибка называет причину, строки совпадений или похожие строки.
- Цель `путь:строка#хеш[-строка#хеш]` из `show --hash` правит целые строки без искомого текста; если строка
  изменилась, правка отклоняется.
- Все операции адресуют исходное содержимое файла: номера строк из `show` действуют для всего пакета;
  пересекающиеся операции — ошибка.
- Одна правка аргументами: `catnip edit replace src/a.php 'old' 'new'` (текст точный, без добавленного перевода
  строки).

После записи catnip печатает изменённые строки (`путь:строка`, `-`/`+`) и запускает фиксеры и проверки из конфига:
изменения фиксеров показаны diff'ом, прошедшие проверки — одной строкой, упавшие — своим выводом.

## Новый файл

```bash
catnip write src/new.go <<'EOF'
package x
EOF
```

## Коды выхода

| Код | Значение |
|---|---|
| 0 | записано, проверки прошли |
| 1 | ничего не записано |
| 2 | ошибка аргументов или конфига |
| 3 | записано, но проверка упала или пакет записан не целиком |
